# Source assets

This folder contains original, high-resolution working files that are useful for future edits but
must not be shipped with the website.

- `documents/` contains editable source documents.
- `gallery/` contains unused or archived team photos.
- `robots/` contains full-resolution robot renders used to produce optimized web images.

Only browser-ready files belong in `public/images/`. Before adding an image there, resize it for its
displayed dimensions, export it as genuine WebP, and use a descriptive kebab-case filename.
